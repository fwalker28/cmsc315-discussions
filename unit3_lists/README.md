# Unit 3 Discussion: List Operations

## Overview

This assignment examines insertion, deletion, and searching in Python lists.

## Learning Objectives

- Insert values into a list
- Delete values from a list
- Search for values in a list
- Analyze list behavior and performance

## Requirements

1. Test insertion at the beginning, middle, and end.
2. Test deletion at the beginning, middle, and end.
3. Search for existing and missing values.
4. Demonstrate edge cases.
5. Create a real-world scenario.

While completing this assignment, I learned more about how lists work in Python and how to add, remove,
and find items in a list. I learned how to use INSERT to add values at different positions and POP to 
remove values while also getting the value that was removed. I also learned how a linear search works by checking
the items in a list one at a time.

One challenge I had was making sure the program did not crash when an invalid index was entered. I solved this by 
checking if the index was within the list before trying to remove anything. Testing different positions also helped
me understand how the list changes when items are added or deleted.

List operations can affect performance depending on where the change happens. For example, inserting or deleting an
item near the beginning can take more work because the other items have to move. Adding something to the end is 
usually faster. This showed me that choosing the right list operation can make a difference when working with larger
amounts of data.
