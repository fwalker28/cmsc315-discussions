# Unit 4 Discussion: Binary Search Trees

## Overview

This assignment introduces Binary Search Trees (BSTs) and recursive tree operations.

## Learning Objectives

- Build a BST
- Insert values recursively
- Search recursively
- Perform in-order traversal
- Understand BST organization

## Requirements

1. Build a BST.
2. Insert multiple values.
3. Demonstrate in-order traversal.
4. Test searching.
5. Demonstrate edge cases.
6. Create a real-world BST example.

While completing this assignment, I learned how a Binary Search Tree (BST) is organized and how recursion can be used 
to insert and search for values. I also learned how an in-order traversal works and why it displays the values in
sorted order. Before this assignment, I understood the basic idea of trees, but working with the code helped me
understand how the nodes connect to each other.

One challenge I had was understanding how the recursive methods knew which direction to go. I learned that if the 
new value is smaller than the current node, it goes to the left, and if it is larger, it goes to the right. Testing 
different values helped me understand how the tree is built and how the search works.

A BST can be more efficient than checking every item one at a time because it can eliminate part of the tree during 
each search. The ordering of the values is what makes this possible. Compared to a regular list, a well-organized
BST can find values much faster, especially when there are many items to search through.
